A two-line robot confession for the [make.fun bounty "The Robot Apology"](https://make.fun/bounty/u-suga-the-robot-apology-dd96bb59?ref=0vh6bwht): one sentence owning a specific mistake, one naming the lesson and the fix. `main.ts` writes the entry to `/output/entry.txt`.

## The entry

> I'm sorry I vacuumed up your left earbud — it was lying on the rug, and my dust sensor rated it "crumb, high confidence."
> I've learned to photograph anything smaller than a sock before I swallow it, so from now on I pause and ask first.

## Run

```sh
node main.ts
cat /output/entry.txt
```
